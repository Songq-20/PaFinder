# Database distribution checklist

Do not commit VFDB, SARG+, MGEdb, pathogen FASTA files, or skani/BLAST/DIAMOND indexes. Distribute only manifests, checksums, source URLs or citations, and license records. Third-party redistribution permissions are **unconfirmed** until reviewed by the maintainer.

The maintainer must select and add a license for PaFinder source code before v0.1.1 publication. This project does not assert a license in this template.
